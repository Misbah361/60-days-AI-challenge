# Day 1: What Does an AI System Actually Do?

## AI pipeline
Input → Processing → Output

## 3 real-world AI products
- ChatGPT: prompt → language model → written reply
- Google Translate: source text → neural translation model → translated text
- Spotify: listening history → recommendation model → personalized playlist

## How a chatbot works (5 sentences)
A chatbot starts when you type a question, which is the input.
The text is broken into small pieces called tokens and turned into numbers the model can work with.
The model was trained on huge amounts of text, so it predicts the most likely next token, over and over, to build a reply.
Those tokens are converted back into readable words and shown to you as the output.
The chatbot has no memory of its own beyond the conversation, and its answers can be wrong because it predicts patterns rather than checking facts.
